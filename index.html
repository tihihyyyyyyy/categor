🎒 Порівняння комплектів спорядження

Інструмент для організатора: швидко знаходьте спільні та унікальні речі у списках.

Підтримується введення через кому, крапку з комою або з нового рядка.

Результат оновлюється автоматично під час введення.

🤝 Спільне (A ∩ B) 0

Немає елементів

🔹 Лише в А (A − B) 0

Немає елементів

🔸 Лише в Б (B − A) 0

Немає елементів

📦 Усі унікальні (A ∪ B) 0

Немає елементів

⚠️ Обмеження алгоритму (на основі множин Set)

  • Не враховує кількість: якщо в списку вказано «ліхтарик» двічі, множина збереже лише один екземпляр.
  • Чутливість до формулювань: слова «спальник» та «спальний мішок» система вважатиме різними предметами.
  • Не зберігає порядок: для зручності результат сортується за алфавітом.
