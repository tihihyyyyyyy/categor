🎒 Порівняння комплектів спорядження

Інструмент для організатора: швидко знаходьте дублікати та унікальні речі у списках

Підтримується введення через кому, крапку з комою або з нового рядка
Результат оновлюється автоматично під час введення

🤝 Спільне (A & B) 0

🔹 Лише в А (A - B) 0

🔸 Лише в Б (B - A) 0

📦 Усі унікальні (A | B) 0

⚠️ Обмеження алгоритму (на основі множин Set)

  • Не враховує кількість: якщо в списку вказано «ліхтарик» двічі, множина збереже лише один екземпляр.
  • Чутливість до формулювань: слова «спальник» та «спальний мішок» система вважатиме двома різними предметами.
  • Відсутність початкового порядку: елементи множини не зберігають черговість введення, тому для зручності читання результат відсортовано за алфавітом.
